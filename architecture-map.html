Notable Findings

Single-file monolithindex.html is 12 531 lines of vanilla JS, CSS and HTML. Every page, utility, and DB call lives here — no bundler, no modules.
Anon key in sourceThe Supabase anon key (_SB_ANON_KEY) is hard-coded in plain text. Combine with 219 open RLS advisor warnings — public tables may be readable without login.
fpa_derived_formulas single source of truthDerived lines (EBITDA, EBIT, net_inc, fin_cost) are computed server-side by DataManager and stored in fpa_facts. The Hub reads the store; the _arithEval() parser is a fallback only.
OCC write pathAll user cell edits go through fpa_facts_write_occ RPC (reads row_version first, rejects on mismatch). Safe against concurrent edits — but the Cash Workbench (p18) is the only page wired to this path.
p2 lines hardcoded list (~line 3987)Any new derived line_id added to fpa_derived_formulas must also be added to a hardcoded list in loadP2() or it resolves 0. Silent failure risk.
Report Builder drives p2, p17report_templates + report_lines tables (managed in DataManager) now control the P&L and Management Report layouts. Hardcoded fallback still present if template fetch fails.
om_facts table may be emptyApril 2026 O&M data (p11) depends on om_facts being populated. Admin re-upload required; no guard in loadP11().
Groq AI assistantp13 Scenario Planner calls a Supabase Edge Function (groq-chat) backed by a Groq/LLaMA API. Errors are logged to JpsMonitor but the user sees a silent toast.
